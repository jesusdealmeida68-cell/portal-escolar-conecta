# Portal Escolar: Conecta

Criar a Página Inicial do Portal Escolar



Cria uma página inicial moderna, bonita, profissional e responsiva para uma plataforma chamada Portal Escolar.



A página inicial deve funcionar como um portal público de informação escolar, onde qualquer visitante pode consultar notícias, comunicados, eventos e informações sobre as escolas, mesmo sem iniciar sessão.



1. Identidade visual e design



- Criar um design moderno, elegante, organizado e profissional.

- Utilizar azul-escuro, branco e tons de azul-claro como cores principais.

- Utilizar tipografia moderna, legível e com boa hierarquia visual.

- Criar uma experiência visual excelente tanto em telemóveis como em computadores.

- Usar cartões elegantes, imagens escolares, espaços bem distribuídos, cantos arredondados e animações suaves.

- Evitar excesso de elementos, cores exageradas e aparência de um template genérico.

- Criar uma identidade visual consistente para todo o portal.

- A interface deve ser rápida, leve e fácil de utilizar.



2. Página de loading



Antes de apresentar a página inicial, mostrar uma tela de carregamento breve e elegante.



A tela deve conter:



- Logotipo do Portal Escolar.

- Nome da plataforma.

- Uma frase curta relacionada com educação e futuro.

- Uma animação de carregamento moderna e discreta.

- Texto: “A preparar o portal...”.



O loading deve desaparecer assim que os recursos essenciais estiverem prontos. Não deve ficar preso nem obrigar o utilizador a esperar desnecessariamente.



3. Cabeçalho



Criar um cabeçalho moderno contendo:



- Logotipo e nome Portal Escolar.

- Menu de navegação com: Início, Notícias, Escolas, Eventos e Sobre.

- Botão destacado “Entrar”.



No telemóvel, transformar o menu num menu compacto e funcional.



O botão “Entrar” deve encaminhar para a página de autenticação já definida ou para uma rota de login preparada para integração futura.



4. Área principal de destaque



Criar uma secção de destaque visualmente forte, com uma fotografia relacionada com o ambiente escolar, estudantes ou educação.



Adicionar:



- Uma pequena identificação, como “EDUCAÇÃO • COMUNIDADE • FUTURO”.

- Um título inspirador relacionado com educação.

- Um texto curto explicando que o portal reúne informações, notícias e novidades das escolas.

- Um botão “Explorar notícias” que leva à secção de notícias.

- Um botão “Conhecer escolas” que leva à secção das instituições.



A composição deve ser bonita, moderna e equilibrada, sem ocupar desnecessariamente todo o ecrã.



5. Secção de últimas notícias



Criar uma secção chamada “Últimas notícias”.



Apresentar as notícias em cartões com:



- Fotografia de capa.

- Categoria da notícia.

- Título.

- Pequeno resumo.

- Nome da escola ou instituição responsável.

- Data de publicação.

- Botão ou link “Ler notícia”.



Criar um cartão de destaque para a notícia principal e cartões menores para as restantes.



Adicionar um botão “Ver todas as notícias”.



As notícias devem ser apresentadas por ordem cronológica, com possibilidade de destacar publicações importantes.



6. Categorias de publicações



Organizar as publicações em categorias, como:



- Notícias escolares.

- Comunicados oficiais.

- Eventos.

- Calendário escolar.

- Projetos educativos.

- Informações sobre matrículas.



Criar filtros funcionais para permitir que os visitantes encontrem facilmente o conteúdo que procuram.



7. Secção de escolas



Criar uma secção chamada “Conhece as nossas escolas”.



Cada cartão de escola pode apresentar:



- Nome da instituição.

- Logotipo ou fotografia.

- Localização geral.

- Breve descrição.

- Link “Ver escola”.



Preparar a interface para que, futuramente, cada escola tenha uma página pública com informações, notícias e eventos próprios.



Não inventar nomes de escolas reais. Se ainda não existirem dados, apresentar um estado vazio elegante, explicando que as instituições serão disponibilizadas quando forem registadas.



8. Secção de eventos e calendário



Criar uma área para apresentar próximos eventos escolares, com:



- Nome do evento.

- Escola organizadora.

- Data.

- Local ou informação de localização.

- Pequena descrição.



Adicionar um link “Ver calendário”.



Preparar a estrutura para que os eventos sejam geridos pela administração e apresentados automaticamente após publicação.



9. Secção de comunicados importantes



Criar uma área visualmente distinta para comunicados oficiais.



Permitir apresentar:



- Avisos importantes.

- Informações sobre matrículas.

- Alterações de calendário.

- Comunicados institucionais.



Cada comunicado deve apresentar título, data, instituição responsável e conteúdo resumido.



Os comunicados devem ser publicados apenas por utilizadores administrativos autorizados.



10. Rodapé



Criar um rodapé profissional contendo:



- Logotipo e nome Portal Escolar.

- Breve descrição da plataforma.

- Links para Início, Notícias, Escolas, Eventos e Sobre.

- Contactos oficiais, quando forem fornecidos.

- Política de privacidade.

- Termos de utilização.

- Informação de direitos reservados.



Não inventar contactos, moradas ou dados institucionais.



11. Funcionamento e integração futura



Preparar a página para integração com uma base de dados, preferencialmente Supabase.



A estrutura deve permitir futuramente:



- Carregar notícias reais publicadas pela administração.

- Carregar escolas registadas.

- Carregar eventos e comunicados.

- Filtrar notícias por categoria e instituição.

- Abrir páginas completas de notícias e escolas.

- Atualizar a página automaticamente quando houver novas publicações.



Não utilizar dados falsos como se fossem notícias reais. Se forem necessários dados temporários para desenvolver a interface, identificá-los claramente como demonstração e facilitar a sua substituição por dados reais.



12. Requisitos técnicos e qualidade



- Utilizar React, TypeScript, Tailwind CSS e componentes reutilizáveis, se esta for a stack já existente no projeto.

- Manter o código organizado e fácil de expandir.

- Garantir responsividade em telemóveis, tablets e computadores.

- Otimizar as imagens e evitar carregamentos excessivos.

- Implementar estados de carregamento, erro e ausência de conteúdo.

- Garantir acessibilidade, contraste adequado e navegação por teclado.

- Não criar botões decorativos sem funcionalidade.

- Não modificar nem quebrar funcionalidades existentes.

- Não criar páginas privadas de aluno, professor ou administração nesta etapa.

- Não implementar autenticação fictícia.

- Não alterar a estrutura existente da base de dados sem necessidade.



Resultado esperado



Uma página inicial completa, bonita e profissional para o Portal Escolar, que combine a apresentação institucional com um portal de notícias escolares.



O visitante deve conseguir conhecer a plataforma, consultar notícias e comunicados públicos, explorar escolas e eventos e encontrar facilmente o botão “Entrar”.



Nesta etapa, concentra-te exclusivamente na página inicial pública e na experiência de loading. Coloca imagens
